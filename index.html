ABOUT THE PROJECT

A web adaptation of the Digital Wallet Simulator.

This is an simulation. It does not connect to real banking systems, payment gateways or real money. The Node.js server reads and writes wallet data to the single project file data.json. Browser localStorage is not used as a second wallet database.
